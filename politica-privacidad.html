Política de privacidad

Esta política explica cómo trata los datos la aplicación “Vehículo Eléctrico”.

Responsable

Carlos Peña Laguna es el responsable de esta herramienta de análisis orientativo de viabilidad de vehículo eléctrico.

Datos que introduce el usuario

La aplicación solicita información sobre uso del vehículo, costes energéticos, presupuesto e infraestructura de carga para generar una estimación personalizada. Esa información se procesa en el propio dispositivo y no se envía a servidores externos.

Recogida y compartición de datos

La aplicación no recoge datos personales, no comparte datos con terceros, no utiliza analítica, no muestra anuncios y no incorpora SDKs externos de seguimiento.

Consulta opcional de red de recarga

La sección “Red de recarga cercana” permite buscar puntos de recarga por ciudad, coordenadas o ubicación del dispositivo. Si el usuario utiliza esta función, la aplicación envía al proxy seguro de la herramienta las coordenadas aproximadas y el radio elegido para consultar mapa REVE. La clave de acceso a mapa REVE no se expone en el navegador y esta consulta no modifica el score principal del análisis.

Los datos mostrados proceden de RED ELÉCTRICA DE ESPAÑA, S.A.U. / mapa REVE. La herramienta no usa esa consulta para analítica, publicidad ni seguimiento, y no almacena historiales de ubicación en el propio frontend.

La geolocalizacion solo se solicita si el usuario pulsa "Usar mi ubicacion". Tambien puede usarse la herramienta sin permitir geolocalizacion, buscando por localidad o coordenadas. El boton "Restablecer busqueda" limpia la consulta de recarga cercana de la sesion actual sin borrar las respuestas del analisis principal.

Almacenamiento local

Si el usuario mantiene activada la opción de guardar datos, las respuestas pueden almacenarse localmente en el dispositivo mediante almacenamiento local del navegador o del WebView. Este guardado sirve únicamente para no perder el análisis al recargar o volver a abrir la herramienta.

Cómo borrar los datos

El usuario puede borrar los datos usando la opción de nuevo análisis o eliminando los datos de la aplicación desde los ajustes del dispositivo.

Menores

La herramienta está pensada para un público general y adulto interesado en evaluar una compra de vehículo. No está dirigida específicamente a menores.

Contacto

Para consultas relacionadas con esta política de privacidad, puede usarse el contacto del desarrollador indicado en la ficha de Google Play.
