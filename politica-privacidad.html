Política de privacidad

Esta política explica cómo trata los datos la aplicación “¿Me compro un coche eléctrico?”.

Responsable

Carlos Peña Laguna es el responsable de esta herramienta de análisis orientativo de viabilidad de vehículo eléctrico.

Datos del análisis principal

La aplicación solicita información sobre uso del vehículo, costes energéticos, presupuesto e infraestructura de carga para generar una estimación personalizada. Esa información se procesa en la propia herramienta y no se envía a un backend propio de análisis.

Almacenamiento local

Si el usuario mantiene activada la opción de guardar datos, las respuestas pueden almacenarse localmente en el dispositivo mediante almacenamiento local del navegador o del WebView. Este guardado sirve únicamente para no perder el análisis al recargar o volver a abrir la herramienta.

Consulta opcional de red de recarga

La sección “Red de recarga cercana” permite buscar ubicaciones de recarga por localidad, coordenadas o ubicación del dispositivo. Si el usuario utiliza esta función, la aplicación envía al proxy seguro de la herramienta las coordenadas y el radio elegido para devolver ubicaciones disponibles en la zona.

La geolocalización solo se solicita si el usuario pulsa “Usar mi ubicación”. También puede usarse la herramienta sin permitir geolocalización, buscando por localidad. La ubicación no se usa para publicidad, perfilado, venta de datos ni seguimiento de usuarios.

Los datos mostrados proceden de RED ELÉCTRICA DE ESPAÑA, S.A.U. / mapa REVE. La herramienta no representa afiliación oficial, no garantiza exhaustividad o disponibilidad en tiempo real y la consulta no modifica el score principal del análisis.

Fuente oficial de mapa REVE: https://www.mapareve.es. Documentación oficial de la API: https://www.mapareve.es/docs/api/external/v1.

Recogida, compartición y terceros

La aplicación no crea cuentas, no muestra anuncios, no incorpora compras integradas y no utiliza SDKs externos de analítica. La consulta de recarga cercana se realiza mediante HTTPS a través del Worker seguro de la herramienta. La clave de acceso a mapa REVE no se expone en el navegador ni en la aplicación Android.

La web está alojada en GitHub Pages y el proxy de recarga funciona en Cloudflare Workers, por lo que esas plataformas pueden tratar datos técnicos necesarios para servir la página o responder la consulta, como direcciones IP y registros técnicos de conexión, conforme a sus propias políticas.

Cómo borrar los datos

El usuario puede borrar los datos usando la opción de nuevo análisis, restableciendo la búsqueda de recarga cercana o eliminando los datos de la aplicación desde los ajustes del dispositivo.

Menores

La herramienta está pensada para un público general y adulto interesado en evaluar una compra de vehículo. No está dirigida específicamente a menores.

Contacto

Para consultas relacionadas con esta política de privacidad, puede usarse el contacto del desarrollador indicado en la ficha de Google Play.
